# Reglas del proyecto

Seguir siempre `.cursor/rules/api.mdc` (fuente única, compartida con Cursor):

- Ningún método con más de 50 líneas de código efectivas.
- Sin código duplicado ni código muerto.
- Todo código nuevo documentado (clases, métodos y lógica no trivial).
- Todo módulo expuesto vía API con decoradores de Swagger completos.
